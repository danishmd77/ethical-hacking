4 Absolute Basics — The Terminal

What is a terminal?

A text window where you talk to the computer by typing commands instead of clicking. Open it with Ctrl + Alt + T.

You will see something like:

┌──(dan㉿kali)-[~]
└─$
  • dan — your username
  • kali — computer name
  • ~ — your home folder (/home/dan)
  • $ — ready for a command (# means root)

Anatomy of a command

command   -options   target
   │          │        │
   │          │        └── what to act on
   │          └────────── how to do it (starts with -)
   └───────────────────── what program to run

Example: ls -l /home

Your first 4 commands

CommandMeaningExample
pwdPrint Working Directory — where am I?pwd
lsList — what is in this folder?ls
cdChange Directory — go somewherecd Downloads
clearClear the screenclear
  • cd .. — go up one folder
  • cd (alone) — go home
  • ~ — home folder

Superpowers

  • Tab — auto-complete a file or folder name
  • ↑ / ↓ — previous / next command
  • command --help — quick help
  • man command — full manual (q to quit)

5 First Week Checklist

  • Open the terminal with Ctrl + Alt + T
  • Run pwd and understand the output
  • Run ls and see your folders
  • Move into a folder with cd, then back with cd ..
  • Use Tab to auto-complete a name
  • Use ↑ to bring back an old command
  • Watch NetworkChuck Episode 1 and type everything
  • Write 5 lines of notes

6 Glossary — plain English

WordMeaning
TerminalText window for typing commands
CommandAn instruction you type and press Enter
DirectoryAnother word for folder
PathThe address of a file or folder, like /home/dan/Downloads
~Shortcut for your home folder
RootThe administrator account with full power
IP addressThe address of a machine on a network
PortA numbered “door” on a machine for a specific service
ProtocolThe agreed rules for how two machines talk
TCPReliable connection (like a phone call)
UDPFast, no guarantee (like a postcard)
ServiceA program listening on a port, waiting for connections
